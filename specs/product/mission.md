# Lost&Found UEx - Misión del producto

## Idea del producto

Lost&Found UEx es una aplicación web destinada a facilitar la gestión de objetos perdidos y encontrados en la Universidd de Extremadura

El sistema debe permitir a los usuarios:

1. Registrar un objeto perdido o encontrado.
2. Consultar los objetos registrados.
3. Buscar y filtrar objetos según diferentes criterios.
4. Solicitar la recuperación de un objeto encontrado.
5. Proporcionar información que permita demostrar la pertenencia del objeto.
6. Consultar el estado de sus solicitudes.

## Problema que se quiere resolver

La gestión de objetos perdidos puede realizarse de forma fragmentada mediante comunicaciones informales, consultas presenciales o diferentes canales independientes. Esto puede provocar que:

- Los usuarios no sepan dónde consultar los objetos encontrados.
- La información sobre los objetos esté dispersa.
- Sea difícil localizar un objeto concreto.
- No exista un proceso claro para solicitar su recuperación.
- No se conozca el estado de una solicitud.
- Los responsables tengan dificultades para mantener un seguimiento de las devoluciones.

## Usuarios principales

| Usuario | Necesidad |
|---|---|
| **Usuario** | Registrar, buscar y consultar objetos perdidos o encontrados, así como solicitar su recuperación de forma clara. |
| **Responsable** | Gestionar los objetos encontrados, revisar las solicitudes de recuperación y controlar las devoluciones. |
| **Administrador** | Mantener la información necesaria para el funcionamiento de la aplicación, como categorías y ubicaciones. |

## Propuesta de valor

Lost&Found UEx reúne en una única experiencia el registro, la consulta y la recuperación de objetos perdidos y encontrados.

Frente a una gestión fragmentada o informal, proporciona:

- Un punto centralizado para consultar los objetos registrados.
- Información organizada y comprensible.
- Búsqueda y filtrado para localizar objetos.
- Un proceso definido para solicitar su recuperación.
- Información sobre el estado de los objetos y las solicitudes.
- Un mecanismo para que los responsables puedan revisar las reclamaciones.
- Una representación concreta del servicio que puede ser revisada y evaluada por terceros.

## Declaración de misión

La misión de Lost&Found UEx es hacer que la gestión de objetos perdidos y encontrados en el entorno universitario resulte clara, organizada y fiable para los usuarios, proporcionando al mismo tiempo a los responsables una herramienta centralizada para gestionar las solicitudes de recuperación y controlar las devoluciones.

## Experiencia deseada

Lost&Found UEx debe ofrecer una experiencia:

- **Centrada:** orientada a resolver de forma directa la necesidad de encontrar o recuperar un objeto.
- **Clara:** la información, las acciones y los siguientes pasos deben ser comprensibles.
- **Continua:** cada paso del proceso debe relacionarse coherentemente con el anterior.
- **Transparente:** el sistema debe informar del resultado de las acciones y del estado de las solicitudes.
- **Recuperable:** los errores corregibles deben ofrecer una forma clara de continuar.
- **Fiable:** la información y los estados mostrados deben ser consistentes.
- **Inclusiva:** la aplicación debe poder ser utilizada por personas con diferentes capacidades.
